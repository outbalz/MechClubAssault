# 돌격! 메카동아리!

![메카동아리 로고](./MechClub_game_Icon.png)

돌격! 메카동아리는 턴제 전술 메카 배틀 로그라이크 게임 입니다.

전술적인 선택으로 적의 움직임을 예측하고 동아리 부원들에게 지시를 내려 동아리를 승리로 이끄세요!
멕화고교 동아리 부원들과 함께 전국대회 우승의 꿈을 키워나가세요!

##턴제 전술 메카 배틀
매 턴마다 부원들에게 전술적인 지시를 내려서 결정적인 순간을 연출하세요!
적의 움직임을 예측하고 한발 앞서 나가세요!

##로그라이크 게임플레이
새 게임을 시작할 때마다 새로운 부원들을 맞이하고 다양한 모듈을 수집하세요!
매번의 게임에서 다양하도 독특한 게임플레이를 시도해 보세요!
